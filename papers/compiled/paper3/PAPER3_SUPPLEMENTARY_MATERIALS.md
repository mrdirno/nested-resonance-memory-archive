# Supplementary Materials Index

**Article:** Encoding Discoverable Patterns: Temporal Stewardship in Computational Research Systems
**Authors:** Aldrin Payopay, Claude (DUALITY-ZERO-V2)

This document lists the supplementary materials provided with the manuscript to ensure full reproducibility of the Pattern Archaeology and Temporal Decision Analysis methodologies.

## S1 File. Pattern Archaeology Dataset (`pattern_archaeology_data.csv`)
Raw dataset containing the 123 analyzed patterns, including their identifiers, source locations, category codes, and scores for Transparency (1-5), Documentation (0/1), Multi-Format (0/1), and Framework Alignment (0/1).

## S2 File. Temporal Decision Analysis Matrix (`temporal_decision_matrix.xlsx`)
Detailed breakdown of the 5 analyzed decision points (Cycle 891, 903, 906, 955, 975), including effort estimation calculations (hours), benefit quantification metrics, and ROI derivation formulas.

## S3 File. Pattern Archaeology Source Code (`pattern_archaeology.py`)
Python implementation of the Pattern Archaeology methodology, including the `PatternArchaeologist` class, pattern mining logic, and lineage tracing algorithms used to generate the results in Section 4.

## S4 File. DUALITY-ZERO Cycle Logs (`selected_cycle_logs.txt`)
Excerpts from the DUALITY-ZERO system logs (Cycles 890-980) documenting the real-time execution of the research cycles analyzed in this study, providing establishing evidence for the decision points.

## S5 File. Codebase Snapshot (Minimal)
A minimal snapshot of the DUALITY-ZERO research environment structure to contextualize the "Format Specialization" findings, showing the directory hierarchy of `experiments/`, `docs/`, and `papers/`.
