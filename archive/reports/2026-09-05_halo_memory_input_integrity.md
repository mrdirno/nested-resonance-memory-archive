# HALO preserved-input integrity check

Author: Aldrin Payopay · September 5, 2026 · GPL-3.0-only

**All requested integrity and numeric-validity checks passed for the nine preserved runs.** This is an input audit, not a memory estimate or physics result.

- All 18 raw/JSON files matched their recorded SHA-256 and byte counts (28,704,849 bytes).
- Each raw file contained exactly 3,145,728 bytes: 24 × 32 × 32 × 32 values interpreted as little-endian float32.
- All 7,077,888 density cells were finite and nonnegative; nonfinite count 0, negative count 0.
- All 216 epoch totals were finite and positive. Totals range from 4095.99680567 to 4095.99975374 in stored-density units.
- Metadata schema, pair identities and recorded mesh dimensions matched. Recorded page-error count was zero across these nine JSON records.
- A second hash pass found no changes to any input or the preservation manifest during inspection. No input was written.

The [machine-readable receipt](2026-09-05_halo_memory_input_integrity.json) contains each file hash, all epoch totals, per-run findings and the runtime. It was generated by [the reusable audit script](../../analysis/halo_memory_input_integrity.py) through `automation/run_background.py`; the execution log is local at `logs/halo_memory_input_integrity_20260905.log`.

Inputs reside under `/Volumes/dual/DUALITY-ZERO-V2/experiments/results/halo/memory_estimator_qualification/`. The raw files and preservation manifest are local-only and are not supplied by a public Git clone. The nine runs were selected exploratorily after the original audit; they are not a confirmatory holdout. Matching the preservation manifest verifies this copy against that record, not independent authenticity of the original experiment.

The [historical writer](../../tests/halo/memory_prereg_run.js) writes native-endian `Float32Array` bytes without an endian marker; the [existing loader](../../experiments/halo/memory_prereg_analyze.py) likewise used native float32. This script explicitly interprets little-endian bytes, consistent with the recorded Apple M4 Pro capture. Exact byte length establishes compatibility with the declared array shape, not independent verification of spatial axis semantics.

Positive density totals are numeric validity checks, not a conservation result. No estimator, surrogate, spatial-support diagnostic, particle simulation or inference about NRM was performed. The [proposed estimator qualification](../../docs/halo/NEXT_MEMORY_ESTIMATOR.md) remains a separate next step.
