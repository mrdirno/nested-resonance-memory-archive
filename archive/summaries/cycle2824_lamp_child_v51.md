# Cycle 2824: The Minkowski Question Mark (Child 116)

**Date:** Dec 4, 2025
**Objective:** Create "Child 116" lamp design based on favorites, exploring Fractal Function Graphs.

## Methodology
- **Algorithm:** Minkowski Question Mark Function `?(x)`.
- **Math:** A singular function defined by the continued fraction expansion of `x`. It maps rationals to dyadic rationals, creating a "Devil's Staircase" profile.
- **Mapping:** The function graph `y = ?(x)` is wrapped around the cylinder, creating a series of steps and cliffs.
- **Structure:** The graph forms a ribbon that spirals up the form, reinforced by vertical ribs and a Gyroid lattice.
