# Cycle 2826: The Cantor Function (Child 118)

**Date:** Dec 4, 2025
**Objective:** Create "Child 118" lamp design based on favorites, exploring the Devil's Staircase.

## Methodology
- **Algorithm:** Cantor Function (Devil's Staircase) Recursive Evaluation.
- **Math:** `F(x)` is calculated by expressing `x` in base 3, handling the removed middle third as a plateau, and mapping to a base 2 value. This creates a continuous function that is constant almost everywhere.
- **Mapping:** The function `z = F(u)` wraps around the cylinder, creating a spiral of flat plateaus connected by sharp rises (at the Cantor set points).
- **Structure:** The staircase ribbon is thickened and reinforced by a dense Gyroid lattice to ensure the disconnected plateaus are physically supported.
