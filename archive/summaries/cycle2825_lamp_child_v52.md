# Cycle 2825: The Weierstrass Function (Child 117)

**Date:** Dec 4, 2025
**Objective:** Create "Child 117" lamp design based on favorites, exploring Continuous Non-Differentiable Functions.

## Methodology
- **Algorithm:** Weierstrass Function Summation.
- **Math:** `sum(0.5^n * cos(3^n * pi * x))` for `n=0..8`.
- **Property:** The resulting curve is a fractal "monster" that has no derivative at any point (infinitely jagged at all scales).
- **Structure:** The function modulates the vertical position of ribbons wrapping around the cylinder.
- **Reinforcement:** Vertical ribs and a Gyroid lattice hold the jagged ribbons in place.
