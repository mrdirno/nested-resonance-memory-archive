# Cycle 2819: The Barnsley Fern (Child 112)

**Date:** Dec 4, 2025
**Objective:** Create "Child 112" lamp design based on favorites, exploring Affine Transformation Fractals.

## Methodology
- **Algorithm:** Barnsley Fern IFS (Iterated Function System).
- **Fractal:** Generated by a probabilistic "Chaos Game" applying 4 affine transformations to a point, simulating the self-similar growth of a fern leaf.
- **Projection:** The 2D point cloud is mapped to spherical coordinates `(u,v) -> (theta, phi)` with a twist, wrapping 5 giant ferns around the lamp shade.
- **Structure:** Voxel Painting dilates the point cloud into solid matter, while a background Gyroid lattice ("potting soil") ensures the disconnected leaflets remain physically supported.
