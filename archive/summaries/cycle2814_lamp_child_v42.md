# Cycle 2814: The T-Square Fractal (Child 107)

**Date:** Dec 4, 2025
**Objective:** Create "Child 107" lamp design based on favorites, exploring Recursive Windows.

## Methodology
- **Algorithm:** T-Square Fractal Iterated Function System.
- **Geometry:** Starting with a solid square, recursive smaller squares are added at the corners. (Inverted logic creates windows).
- **Mapping:** The 2D fractal pattern is mapped onto the cylindrical coordinates `(theta, z)` of the lamp shade, repeated 4 times around the circumference.
- **Structure:** A twist along the Z-axis transforms the static grid into a spiral. A secondary Gyroid lattice provides minimal reinforcement in the voids.
