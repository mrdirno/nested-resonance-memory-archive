# Cycle 2811: The Moore Curve (Child 104)

**Date:** Dec 4, 2025
**Objective:** Create "Child 104" lamp design based on favorites, exploring Continuous Loop Space Filling.

## Methodology
- **Algorithm:** Moore Curve L-System.
- **Fractal:** A cyclic variant of the Hilbert curve (Iteration 5) that starts and ends at the same point, forming a perfect loop.
- **Projection:** The 2D square fractal is mapped to spherical coordinates `(theta, phi)` with a twist.
- **Materialization:** Voxel Painting with a thick tube radius creates a dense, winding shell.

- **Flow:** The curve is a single, unbroken loop.
- **Breath:** The uniform spacing of the space-filling curve provides consistent porosity.
- **Jaw-Dropping:** An infinite loop wrapped around a finite sphere.
