# HELIOS-BRIDGE UI (Gate 5.2)

A lightweight React frontend for controlling the Reality Compiler.

## Setup
1. Ensure `src/helios/bridge_api.py` is running on `localhost:5000`.
2. Serve this directory (or a build of it).

## Core Components
1.  **Upload:** Drag-and-drop .obj files.
2.  **Material:** Dropdown selector (Air, Water, Glycerin).
3.  **Fabricate:** Button to trigger the API.
4.  **Status:** Real-time feedback from the API.

## Implementation Plan (Cycle 2353)
We will create a single-file `index.html` with embedded React/Babel for maximum portability (no npm install required for the prototype).
