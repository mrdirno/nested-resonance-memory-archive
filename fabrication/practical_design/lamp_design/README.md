# Helios V2 - "The Void" Series

## Design Philosophy
High-contrast, hollow structures implementing the "Void" aesthetic. 
Prioritizes negative space and arterial structural integrity.

## Components
1.  **Lamp Base V2:**
    *   Dims: 180mm x 20mm
    *   Features: Wide/Slim profile, Anisotropic Gyroid (Linear Gradient).
    *   Mount: 12.5mm Center Hole.

2.  **Lamp Shaft V2:**
    *   Dims: 200mm Height, 55mm Base, 40mm Top.
    *   Features: Arterial Helix (Pure), Variable Density (Center Solid -> Edge Airy).
    *   Mount: Internal solid tube (12mm ID).

3.  **Lamp Shade V2:**
    *   Dims: 194mm Base, 60mm Top, 224mm Height.
    *   Features: Pyramid Taper, Anisotropic Gyroid (Vertical Stretch).
    *   Mount: Washer top (12mm Hole).

## Fabrication
Run `python3 fabrication/scripts/run_helios_full_v2.py` to generate STLs.
STLs are ignored in git to save space (approx 100MB total).
