## 2. Mathematical Definition
**Base Topology:** Schwarz D Gyroid (Same as Artifact 01).
**The Bias Function:** A radial thickness gradient.

$$ T(r) = T_{max} - (T_{max} - T_{min}) \cdot \frac{r}{R} $$

Where:
*   $r$ is distance from center.
*   $T_{max} \approx 0.9$ (Core Thickness).
*   $T_{min} \approx 0.1$ (Edge Thickness).

This creates a continuous transition from a nearly solid core to a delicate, spider-web edge, all within a single continuous mesh.

## 4. Applications (Why Gradient Matters)
1.  **Bone Implants:** Real bone is not uniform. It has a dense cortical shell and a porous trabecular core. This artifact mimics that biological density gradient perfectly.
2.  **Heat Dissipation:** In a heat exchanger, you want high surface area where the heat is generated (core) and high airflow where it escapes (edge).
3.  **RF Lensing (Luneburg Lens):** A sphere with a gradient refractive index (density) can focus radio waves from any direction onto a point on its surface. This artifact is a printable Luneburg Lens.
