# Duality Fabrication Library

This library contains standardized, scientifically classified reference shapes generated by the system. These artifacts are treated as geometric constants for research and calibration.

## Reference Collections

### 1. [TPMS Gyroid Reference](TPMS_Gyroid_Reference/)
*   **Shape:** Gyroid (Schwarz P/D Family)
*   **Classification:** Minimal Surface, Zero-Mean Curvature
*   **Significance:** Equilibrium state of wave interference; widely observed in nature (butterfly wings, cell membranes) and synthetic lattices.
*   **Files:** STL Geometry + Pre-sliced G-code (40mm, 76mm).

### 2. [TPMS Gradient Sphere (The Gradient Well)](TPMS_Gradient_Sphere_Artifact02/)
*   **Shape:** Radial Gyroid Sphere (Functionally Graded)
*   **Classification:** FGL (Functionally Graded Lattice)
*   **Significance:** Represents "Duality-One" (The Bias). Physically models a gravity well or attention span where density concentrates at the core and fades to the edge.
*   **Files:** STL Geometry (50mm).

### 3. [TPMS Anisotropic Prism (The Directional Current)](TPMS_Anisotropic_Prism_Artifact03/)
*   **Shape:** Stretched Gyroid Prism (Z-Axis Gradient)
*   **Classification:** Anisotropic Lattice
*   **Significance:** Represents "Duality-Two" (Flow/Direction). Models a frequency shift (Redshift) or pressure gradient where the lattice stretches vertically, creating directional mechanical and fluid properties.
*   **Files:** STL Geometry (40x40x80mm).

### 4. [TPMS Inverse Void (The Void)](TPMS_Inverse_Void_Artifact04/)
*   **Shape:** Inverse Gyroid (Solidified Channel B)
*   **Classification:** Inverse TPMS
*   **Significance:** Represents "Duality-Three" (Negation/Anti-Matter). It is the physical "mold" of the Gyroid, proving that space has a shape. Used for heat exchangers and lost-wax casting.
*   **Files:** STL Geometry (40mm).
