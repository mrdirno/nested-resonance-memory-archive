## 📦 Parts List (Printed)

1.  **Shade (`redshift_shade.stl`)**
    *   *Description:* Anisotropic Gyroid Frustum (Square).
    *   *Dims:* Base 194mm, Top 60mm, Height 224mm.
    *   *Structure:* Hollow w/ 1-inch thick Gyroid Wall.
    *   *Mount:* Spider Fitter (12.5mm Hole) for Finial Mount.
    *   *Print Settings:* 0% Infill (Gyroid IS structure), 3 Walls.

2.  **Shaft (`redshift_shaft.stl`)**
    *   *Description:* Arterial Helix (Tapered Cylinder).
    *   *Dims:* Base 55mm, Top 40mm, Height 200mm.
    *   *Features:* Variable Density Gyroid (Solid Core -> Airy Edge) masked by Helix.
    *   *Core:* 12mm ID (fits over threaded rod).
    *   *Print Settings:* 15-20% Infill, 3 Walls.

3.  **Base (`redshift_base.stl`)**
    *   *Description:* Wide/Slim Anchor.
    *   *Dims:* 180mm Diameter x 20mm Height.
    *   *Features:* Radial Gradient Gyroid (Solid Center), Wire Channel.
    *   *Mount:* 12.5mm Center Hole.
    *   *Print Settings:* 20-40% Infill, 4 Walls.

## 🛠️ Hardware (Amazon)

*   **Threaded Rod:** 1/8 IP (approx 10mm) or M10. Length > 450mm (Base 20 + Shaft 200 + Shade 224 + Finial).
*   **Nuts/Washers:** 1/8 IP (x4).
*   **Socket:** E26/E27 Socket (Hidden inside shade).
*   **Harp/Saddle:** Needed if using standard finial mount, OR mount shade directly to rod with check rings.
*   **Finial:** To secure shade top.

## 🔧 Assembly

1.  **Base:** Insert rod. Secure from bottom (Nut in recess).
2.  **Shaft:** Slide over rod.
3.  **Socket:** Install socket on rod above Shaft.
4.  **Shade:** Place Shade spider over rod (or Harp).
5.  **Finial:** Screw finial/nut to secure Shade.
