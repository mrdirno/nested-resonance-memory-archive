# HELIOS LAMP SERIES 01: COSMOLOGICAL EVOLUTION

## Overview
A collection of 10 procedural lamp designs exploring the evolution of the universe from the Big Bang to the Final Theory. Each design consists of a Shade, Shaft, and Base, optimized for FDM 3D printing.

## Physical Protocol
*   **Socket:** Standard E26/E27 Socket.
*   **Mounting:** All shades use a **Spider Fitter** (40mm Solid Hub + 4 Spokes) with a 12.5mm hole, compatible with standard 1/8 IP pipe (nipple) and finials.
*   **Hardware:** 1/8 IP Threaded Rod, Nuts, Washers.
*   **Max Dimensions:** Designed for 220x220x250mm Build Volume (Ender 3). Shade Diameter 200mm.

## Printing
*   **Material:** PETG or PLA.
*   **Layer Height:** 0.2mm.
*   **Supports:** None required for any design (Self-supporting geometry).
*   **Infill:** 15-20% (Gyroid preferred).

## Source Code
All geometry is generated procedurally via Python scripts in `fabrication/furniture/lamp_series_01/`.
