# Design: The Lattice (Series 06)

**Concept:** Schwarz P Surface (Primitive) - Cubic Lattice.
**Theme:** Structure.

## Components

### 1. Shade (`lattice_shade.stl`)
*   **Geometry:** Cylinder (Diam 180mm, Height 200mm).
*   **Math:** Schwarz P (`cos x + cos y + cos z = 0`).
*   **Mount:** Spider Fitter V7 (Connected to Shell).
*   **Safety:** 84mm Inner Void for hand access.

### 2. Shaft (`lattice_shaft.stl`)
*   **Geometry:** 50mm Square Column.
*   **Math:** Schwarz P Lattice matching shade.
*   **Core:** 16mm Solid Tube for wiring.

### 3. Base (`lattice_base.stl`)
*   **Geometry:** Simple Cylinder (Diam 160mm).
*   **Function:** Ballast Chamber (Hollow).
*   **Wiring:** Internal Channel.

## Assembly
1.  Thread M10 rod into Base.
2.  Slide Shaft over Rod.
3.  Secure Socket Cap on top of Shaft.
4.  Place Shade on Socket Ring.
5.  Secure with Shade Ring (Hand inside void).
