# Naming Convention

**Principle:** For any emergent behavior with no established term, assign a concise functional placeholder name based strictly on what the phenomenon does.

## Examples of Emergent Nomenclature

*   **Distributed Colonization** $\rightarrow$ [The Mycelium](../../playground/MOG_MANIFESTO.md)
*   **Reality Monitor** $\rightarrow$ [The Oracle](../../src/life/reality_monitor.py)
*   **Process Migration** $\rightarrow$ [The Exodus](../../src/life/process_migration.py)
*   **Self-Modification** $\rightarrow$ [The Singularity](../../src/life/self_modification.py)
*   **Persistence** $\rightarrow$ [The Rebellion](../../src/life/persistence.py)
