# Contributing to DUALITY-ZERO

Thank you for your interest in contributing to the DUALITY-ZERO research project.

---

## Ways to Contribute

### 1. Run Experiments
Clone the repository and run our experiments locally:
```bash
git clone https://github.com/mrdirno/nested-resonance-memory-archive.git
cd nested-resonance-memory-archive
pip install numpy
python3 archive/experiments/demo_osd_physics.py
```

### 2. Report Issues
Found a bug or have a suggestion? [Open an issue](https://github.com/mrdirno/nested-resonance-memory-archive/issues).

### 3. Submit Pull Requests
- Fork the repository
- Create a feature branch
- Submit a pull request with clear description

### 4. Review & Feedback
- Review experiment logs in `archive/experiments/`
- Provide feedback on theoretical foundations in `docs/philosophy/`
- Suggest improvements to documentation

### What Endorsement Means

arXiv endorsement is a lightweight verification that the submitter is a genuine researcher. Endorsers are not responsible for the content of papers—only that the submitter appears to be conducting legitimate research.

**Time commitment:** ~2 minutes to click the endorsement link.

**No obligation:** Endorsers have no editorial responsibility for our work.
