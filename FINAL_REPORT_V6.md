- **Result:** Positive reinforcement loop established. If Agent A says "X" is "FOOD" and Agent B sees "FOOD", Agent B reinforces "X" = "FOOD". If not, it is weakened.

- **Result:** `Brain` can now decode multi-part messages into structured intents (`{target: 'FOOD', direction: 'NORTH'}`). This paves the way for complex instruction transmission.
